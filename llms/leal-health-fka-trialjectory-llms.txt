# Leal Health (fka TrialJectory)

> Leal Health is an AI-powered, patient-first decision-support platform that matches cancer patients to advanced treatments and clinical trials. Its patented NLP engine parses inclusion/exclusion eligibility criteria and connects to ClinicalTrials.gov so patients, caregivers, and oncologists can self-screen against recruiting oncology trials in about two minutes. Pharma, biotech, and CRO customers buy the Patient Match Optimizer SaaS dashboard, which returns de-identified aggregate datasets on patient barriers, motivators, geography, and competitive landscape. Founded as TrialJectory by Tzvia Bader, Avital Gaziel, Guy Gildor, and Noam Geva; rebranded to Leal Health.

Generated by the API Evangelist enrichment pipeline on 2026-07-19 from apis.yml and the artifacts in this repository. Leal Health does not publish an llms.txt of its own (https://leal.health/llms.txt returns 404).

## Important note for agents

Leal Health runs **no public developer program**. There is no OpenAPI definition, no API reference, no SDK, no CLI, no sandbox, no public MCP server, and no developer portal. A live platform API host exists at `https://api.leal.health` — the root path returns HTTP 200 with `{"success":true}`, but every sub-path returns HTTP 401 with an empty body and no `WWW-Authenticate` header. Access is private/partner-only and undocumented. Do not attempt to construct API calls against it; there is no published contract to ground them in.

## Products

- [Patient trial matching (patients & caregivers)](https://webapp.leal.health/search): self-service eligibility screening against recruiting oncology trials.
- [For oncologists](https://www.leal.health/oncologists): clinician-facing matching for a panel of patients.
- [Patient Match Optimizer (pharma / biotech / CRO)](https://www.leal.health/pharma): real-time de-identified dashboard of patient matches, enrollment barriers, site-location fit, and competitive landscape.
